# illuminator — сайт и кабинет оператора

Статический сайт, без сборки. Работает на GitHub Pages как есть.

## Структура
- `index.html` — главная (заставка-комета, каталог, механики, роадмап, промо-ролики, контакты)
- `cabinet.html` — кабинет оператора (подключение, промо, конструктор колеса, ассеты, спецификация, контакты)
- `support.js` — рантайм страниц, `image-slot.js` — слоты изображений
- `assets/brand/` — логотип (`logo-full`, `logo-word`, `logo-dark`), знак `emblem`, горизонт `earth`
- `assets/games/` — обложки игр (`*-l.jpg` ландшафт, `*-p.jpg` портрет)

## Публикация
Settings → Pages → Deploy from branch → `main` / root.

## Замена ассетов
Файлы можно заменять с теми же именами — пути в коде не меняются. `earth.png` — полоса планеты (1672×260), верх должен уходить в чёрный.
